Plugins · marketplace.json

全部技能

本页数据来自 docs/skills.json，浏览器禁止 file:// 读取本地文件。 请在仓库根目录运行 python -m http.server -d docs 8000，再打开 http://127.0.0.1:8000/。

每个技能一个独立插件，清单在其目录下的 .claude-plugin/plugin.json。列表、版本与触发词由 scripts/build-site-data.mjs 从各 SKILL.md 与 marketplace.json 生成。

Install · 两种方式

一条命令安装

ZCode · 添加插件市场
https://github.com/uwakeme/wake-skills.git

在 ZCode 里添加插件市场时填入仓库地址，之后每个技能可按插件独立安装。

Mavis · skill install
mavis skill install https://github.com/uwakeme/wake-skills

也可只装单个技能：mavis skill install …/tree/main/readme-craft。安装后下一个 session 即可使用。

仓库约定——每个技能一个目录，Mavis 与 ZCode 两种格式共用同一套文件：

<skill-name>/
├── SKILL.md            # 必备，frontmatter 含 name / description
├── references/         # 可选，详细参考（按需回查，不进主 context）
└── .claude-plugin/
    └── plugin.json     # ZCode 插件清单（skills: "." 指向本目录）
